Build and manage WordPress REST API routes visually.

== Description ==

REST Route & Action Manager is a powerful tool for developers to create, configure, and manage custom REST API endpoints without writing boilerplate code.

Features:
* Visual Route Builder: Drag and drop action blocks to define endpoint logic.
* Security Controls: Easily set permission callbacks and authentication requirements.
* Route Management: Centralized dashboard for all your custom endpoints.
* Action Blocks: Built-in support for Database queries, Email notifications, and more.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/wp-rest-route-manager` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Go to Tools -> Custom Routes to start building.

== Frequently Asked Questions ==

= Is this plugin secure? =
Yes, it uses standard WordPress REST API registration and provides whitelisting for permission callbacks to prevent unauthorized execution.
